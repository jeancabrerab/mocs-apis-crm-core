# Mocks de APIs para CRM Core

Proyecto para implementar servicios simulados de las APIs TM Forum utilizadas por CRM Core.

## Objetivo

Permitir que las aplicaciones consumidoras puedan desarrollar y probar integraciones sin depender de los servicios reales.

## Tecnología

- Node.js
- TypeScript
- Express
- Datos de prueba en archivos JSON
- Swagger / OpenAPI
- Docker

## APIs consideradas

- TMF620 - Catálogo de productos
- TMF622 - Órdenes de producto
- TMF629 - Gestión de clientes
- TMF632 - Personas y organizaciones
- TMF637 - Inventario de productos
- TMF638 - Inventario de servicios
- TMF639 - Inventario de recursos
- TMF644 - Privacidad y consentimientos
- TMF646 - Gestión de citas
- TMF651 - Gestión de acuerdos
- TMF663 - Carrito de compras
- TMF666 - Gestión de cuentas
- TMF667 - Gestión documental
- TMF669 - Gestión de roles
- TMF671 - Promociones
- TMF673 - Direcciones geográficas
- TMF674 - Sitios geográficos
- TMF675 - Ubicaciones geográficas
- TMF679 - Calificación de ofertas
- TMF680 - Recomendaciones de productos
